# ForceIA Design System (UI/UX Pro Max)

Generated via ui-ux-pro-max for **ForceIA Operations Console**.

## Dials
- Variance: 4 (balanced)
- Motion: 3 (subtle, 120–180ms)
- Density: 9 (dashboard dense, 8–32px scale)

## Product
AI commercial team operating system (not CRM). Client watches productivity, conversations, meetings, pipeline.

## Style
Modern Dark / Technical Ops — deep black canvas, mono metrics, color only for meaning.

## Anti-patterns (from skill)
- Bright neon / purple-pink AI gradients
- Large marketing hero on dashboard
- Color-only meaning in charts (always label + style)
- Hover-only interactions without focus
- Animation > 200ms for micro feedback
